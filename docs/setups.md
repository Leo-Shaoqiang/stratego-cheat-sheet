# 4x10 Tactical Setups Guide

Battle-tested opening formations and strategic board layouts for competitive and casual play.

Reference: [Interactive Board Setups](https://strategocheatsheet.com/#setups)

---

## 1. Setup A: The Corner Fortress (Defensive Balance)

**Concept**: Conceals the Flag in the back corner (Row 1, Column 1 or 10), insulated behind a protective pyramid of Bombs. High-ranking officers guard the perimeter against early Miner infiltration.

```
Row 4 (Frontline): [ S ] [ 2 ] [ 4 ] [ 2 ] [ 5 ] [ 5 ] [ 2 ] [ 4 ] [ 2 ] [ 6 ]
Row 3 (Midline)  : [ 6 ] [ 7 ] [ B ] [ 8 ] [ 6 ] [ 7 ] [ 8 ] [ B ] [ 7 ] [ 6 ]
Row 2 (Rear Guard): [ 3 ] [ B ] [ 1 ] [ B ] [ 9 ] [ 3 ] [ 10] [ B ] [ 3 ] [ 3 ]
Row 1 (Backline) : [ F ] [ B ] [ 3 ] [ 2 ] [ 2 ] [ 2 ] [ 2 ] [ 4 ] [ 4 ] [ 5 ]
```

- **Pros**: Virtually impenetrable to frontline rushes. Requires opponents to identify and march Miners into the back corner.
- **Cons**: Less offensive mobility in early game; predictable if opponents recognize corner patterns.

---

## 2. Setup B: The Blitzkrieg Rush (Aggressive Breakthrough)

**Concept**: Places the Marshal (`10`), General (`9`), and multiple Scouts on rows 3 and 4 to execute early corridor dominance, while the Flag is hidden in row 2 behind a deceptive decoy wall.

```
Row 4 (Frontline): [ 2 ] [ 9 ] [ 2 ] [ 10] [ 2 ] [ 8 ] [ 2 ] [ 8 ] [ 2 ] [ 7 ]
Row 3 (Midline)  : [ 6 ] [ 6 ] [ 7 ] [ 7 ] [ 6 ] [ 6 ] [ 5 ] [ 5 ] [ 5 ] [ 5 ]
Row 2 (Rear Guard): [ B ] [ F ] [ B ] [ 4 ] [ 4 ] [ 4 ] [ 4 ] [ 3 ] [ 3 ] [ 3 ]
Row 1 (Backline) : [ 1 ] [ B ] [ B ] [ B ] [ B ] [ 3 ] [ 3 ] [ 2 ] [ 2 ] [ S ]
```

- **Pros**: Controls board tempo immediately. Forces opponents onto the defensive before they can scout your positions.
- **Cons**: High risk if the Marshal steps on an early Bomb or falls victim to an opposing Spy.

---

## 3. Setup C: The Shoreline Trap (Chokepoint Control)

**Concept**: Concentrates Bombs and high officers directly adjacent to the lake corridors (columns 1-2, 5-6, 9-10), ambushing enemy pieces as they attempt to exit the natural chokepoints.

---

## 💡 Key Tactical Tips

1. **Protect Your Miners**: Keep at least 2 Miners safely behind your frontline until the opponent's Bombs are located.
2. **Spy Escort**: Keep your Spy within 1-2 squares of your General or high officer; use them as bait to lure out the enemy Marshal.
3. **Scout Verification**: Never attack an unknown piece with your Marshal without probing it with a Scout or Sergeant first.
